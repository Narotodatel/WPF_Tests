# Описание проекта

Разработано WPF-приложение для расчета результатов демонстрационного экзамена.

Приложение позволяет:

- выбрать уровень экзамена;
- ввести баллы за модули;
- рассчитать сумму баллов;
- определить процент выполнения;
- вывести оценку по 5-балльной шкале.

## Уровни экзамена

## Проверка данных

Реализована проверка:

- корректности ввода;
- диапазона значений;
- обработки ошибок через MessageBox.

# Автоматизированное тестирование

Разработаны автоматизированные тесты для:

- корректных данных;
- граничных значений;
- некорректных данных;
- проверки исключений.
