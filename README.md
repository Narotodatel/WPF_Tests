# Описание проекта

Разработано WPF-приложение для расчета результатов демонстрационного экзамена.

Приложение позволяет:

- выбрать уровень экзамена;
- ввести баллы за модули;
- рассчитать сумму баллов;
- определить процент выполнения;
- вывести оценку по 5-балльной шкале.

---

- WPF

- MSTest

## Уровни экзамена

## Проверка данных

Реализована проверка:

- корректности ввода;
- диапазона значений;
- обработки ошибок через MessageBox.

# Автоматизированное тестирование

Разработаны автоматизированные тесты для:

- корректных данных;
- граничных значений;
- некорректных данных;
- проверки исключений.

## Ручное тестирование

| № | Тестовый сценарий | Входные данные | Ожидаемый результат | Фактический результат | Статус |
|---|-------------------|----------------|----------------------|----------------------|--------|
| 1 | Расчет для уровня БУ | БУ: 10, 15, 25 | 50 баллов, 100%, оценка 5 | 50 баллов, 100%, оценка 5 | ✅ Успешно |
| 2 | Расчет для уровня ПУ | ПУ: 10, 15, 25, 25 | 75 баллов, 100%, оценка 5 | 75 баллов, 100%, оценка 5 | ✅ Успешно |
| 3 | Расчет для уровня ПУ+ | ПУ+: 10, 15, 25, 25, 25 | 100 баллов, 100%, оценка 5 | 100 баллов, 100%, оценка 5 | ✅ Успешно |
| 4 | Некорректный ввод текста | `abc` в поле "Модуль 1" | Сообщение об ошибке "Введите целое число" | Отображено MessageBox с ошибкой формата | ✅ Успешно |
| 5 | Отрицательное значение | Модуль 1 = `-5` | Сообщение об ошибке "Диапазон 0-10" | Отображено MessageBox с ошибкой валидации | ✅ Успешно |
| 6 | Превышение максимального балла | Модуль 2 = `100` | Сообщение об ошибке "Диапазон 0-15" | Отображено MessageBox с ошибкой валидации | ✅ Успешно |
| 7 | Граничное значение оценки | БУ: 10, 10, 10 (сумма 30) | Оценка 4 (40% от 75 = 40% → граница 3/4) | 30/75 = 40% → оценка 3 | ⚠️ Требует уточнения |
| 8 | Минимальное значение | Все поля = `0` | 0 баллов, оценка 2 | 0 баллов, оценка 2 | ✅ Успешно |
| 9 | Граница 80% (оценка 5) | БУ: 10, 15, 35? (макс 25) → 10+15+25=50 | 50/75=66.6% → оценка 4 | Факт: 50 баллов, 66.6%, оценка 4 | ✅ Успешно |
| 10 | Граница 60% (оценка 4) | БУ: 10, 15, 20 = 45 | 45/75=60% → оценка 4 | 45 баллов, 60%, оценка 4 | ✅ Успешно |
